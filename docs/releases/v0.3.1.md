# Release Notes v0.3.1

Released: 2026-11-26

## Highlights

- **The firewall is checked before each ship.** When a tool gives the
  admin addresses and the host its `lightsailName`, the first step of each
  stack's deploy runbook runs `host ports`. A firewall change that closed
  HTTPS is found before a deploy, not after every site behind the host has
  gone dark.
- **Generated pages name no local path.**

## Added

- `Options.AdminCIDRs`: the addresses SSH should be open to. `host ports`
  uses them when `--admin-cidr` is not given, so `host ports <host>` needs
  no flags in a tool that sets them, and each stack's deploy runbook checks
  the host's firewall with them.

## Fixed

- A deploy runbook's page named the program that wrote it by its path.
  Under `go run` that is a temporary build directory under the operator's
  home. The page now names the runbook tool a host tool gives, or this
  program by name, and the commands on pages never carry a temporary build
  path.

## Build

- `make lint` runs golangci-lint with the organization's shared
  configuration, the one CI checks out, so the gofmt and goimports
  formatters run locally as they do in CI. `LINT_CONFIG_REPO` points at the
  checkout of the organization's `.github` repository, `../.github` by
  default.

## Documentation

- The hosts, deploying and embedding guides describe the firewall check
  and `AdminCIDRs`; the README describes `make test` and `make lint`.

## Upgrading

No change is needed. To have deploy runbooks check the firewall, set
`Options.AdminCIDRs` and give each host its `lightsailName`.
